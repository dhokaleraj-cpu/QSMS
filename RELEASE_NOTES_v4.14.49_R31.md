# QCMS v4.14.49 R31 — Android app v3.1.0: Download PDF / Excel, Print, Email on every screen

- **⇩ button in the top bar of every app screen** (records, registers, reports, KPI tables, entries / forms):
  - **Download PDF** – controlled QCMS print (company header, title, printed date and user, details in two columns,
    every table with the header row repeated on each page, "Page i of N"; landscape for wide tables).
  - **Download Excel (.xlsx)** – real Excel workbook: Details sheet + one sheet per table, bold header, frozen
    header row and first column, filter on every column, numbers stored as numbers (codes such as HSN, part,
    order and heat numbers stay text).
  - **View PDF**, **Print** (Android print service: any Wi-Fi / cloud printer or "Save as PDF"),
  - **Email from QCMS** – opens Send Email with the PDF and the Excel file already attached (company mailbox,
    same send log as the website),
  - **Share PDF / Share Excel** (WhatsApp, Gmail, Drive …).
- Registers export all rows with the current status / search filter; record screens have a
  "⇩ Download PDF / Excel · Print · Email" button; entry forms export the filled fields.
- Files are saved to Downloads/QCMS (Android 10+).
- No database change.
