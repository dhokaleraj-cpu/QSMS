# QCMS 4.10.2

Hotfix release for the v4.10.1 Customer Standards Bank.

- Fixes the Part Master `NameError` by importing the shared `part_label` selector helper.
- Adds a visible controlled Standard / Specification file uploader on the first Customer Standard save.
- Keeps the post-save Attachment Manager for download, replacement and password-protected deletion.
- Preserves the existing Customer Standard, Process and Part link schema from v4.10.1.
