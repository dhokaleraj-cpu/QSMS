# QSMS 4.6.0

- Compact high-contrast Export Shipment-style interface with taglines removed.
- RMTC Draft → Pending action on the RMTC entry page.
- Material Inward remains eligible only against Accepted / Accepted Under Reserve RMTC parts.
- Inspection Layout Master linked to Part, Process and Inspection Stage.
- Dimensional layout import from `Dimensional Report.xlsx`.
- Dimensional report with configurable observations and automatic characteristic results.
- MetLAB report generated from approved part/process/stage layouts.
- Accepted, Accepted Under Reserve and Rejected final dispositions.
- Material Inward is released to the next process only after both reports are Accepted or Accepted Under Reserve.
- Heat number and internal heat code are carried through all inspection reports.
