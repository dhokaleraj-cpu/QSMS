# QSMS 4.5.0

Focused live release with:

- Dashboard after login with direct module navigation, status cards and charts.
- RMTC workflow corrected to Draft → Approval Pending → Validated → Final Decision.
- Part-wise final decisions: Accepted, Accepted Under Reserve and Rejected.
- Material Inward entry restricted to accepted RMTC Part Numbers.
- NA-aware RMTC validation.
- Record selector and edit/delete actions above every master/transaction register.
- Password-protected deletion for Material Inward where no downstream transaction exists.
- Supabase live transactions, GitHub-ready source and Streamlit Cloud configuration.
