# QCMS 4.11.1 — High-Contrast Zoho-Inspired White/Blue UI

This release fixes the low-contrast shell/menu regression in QCMS 4.11.0.

## UI
- White high-contrast application header.
- Dark company, page and user text.
- White module rail with dark labels and clear blue active state.
- Compact light submenu with blue current-page indicator.
- Very light warm-to-sky application background.
- Minimal cards/forms/tables with restrained blue accents.

## Navigation
The QCMS 4.11.0 Records centralization remains unchanged. All record/register pages are routed under the main Records module.

## Safety
No Supabase migration is required. Existing QCMS records, users, attachments, secrets and Git history are preserved.
