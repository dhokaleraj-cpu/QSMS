# QSMS Focused Release 4.2.0

Only two top-level workspaces are exposed:

1. **Masters** — Part Master grids, reference masters, Employee Master and Super Admin user controls.
2. **RMTC Entry** — live certificate entry, Part Master validation, submission, validation and approval.

Dashboard, traceability, PPAP, inspection, OSP, calibration and audit screens are intentionally outside this release.
