# QCMS 4.12.6 — Procurement Portal Reference UI

Build: `4126-PROCUREMENT-PORTAL-REFERENCE-UI`

This release is presentation-only. It applies the supplied enterprise procurement portal visual language across QCMS while preserving all v4.12.5 workflows, data and security.

- Deep red `#B20738` application header with Four Star identity.
- White / light-grey `#EFEFEF` application surfaces.
- Arial / Helvetica enterprise typography.
- Thin neutral field and table borders, compact square geometry and flat controls.
- White primary navigation with red active underline.
- Clean red section titles and A/B/C stage headings.
- Blue primary action buttons, dark export buttons and red destructive actions.
- Existing green / amber / red workflow status colours retained.
- No Supabase migration required.
