# QCMS 4.11.7 — Collapsible A→E Complaint Stage Workflow

Customer Complaint and Supplier Complaint entry now use five color-coded expandable stages:

- **A - COMPLAINT DETAILS**
- **B - RESPONSIBILITY**
- **C - PHOTOGRAPHS & MULTIPLE ATTACHMENTS**
- **D - CONTAINMENT / ROOT CAUSE / CORRECTIVE ACTION**
- **E - DEBIT NOTE / COMMERCIAL SETTLEMENT**

Stage headers use a 26px, 900-weight font (100% larger than the historic 13px section-bar title). Stage A opens by default and stages B–E are collapsed by default. Existing Customer/Supplier pastel palettes remain attached to the matching stage. No database migration or data reset is required.

Build: `4117-COMPLAINT-STAGE-EXPANDERS`.
