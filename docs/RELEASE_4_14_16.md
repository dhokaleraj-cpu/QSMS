# QCMS v4.14.16

Controlled additive release for permissions, Purchase Order approval/cancel-reissue and Supply Chain responsibility notifications.

- Explicit User Module Permission → Department Module Default → legacy Role fallback.
- Entry/Create → Validate/Review → Approve permission layers.
- Section Visibility / Edit controls.
- New Purchase Orders are PENDING_APPROVAL until manager approval.
- PO cancel/reissue releases source allocations and preserves replacement lineage.
- RM PO prints Raw Material Type, Material Grade and Section Size.
- Supply Chain stage responsibility notifications and status-coloured Excel exports.
