# QSMS Release 4.8.2

## Automatic Reference Master Codes

New records receive editable codes automatically:

- Customers: `CUST-0001`
- Suppliers: `SUP-0001`
- Steel Mills: `MILL-0001`
- OSP Vendors: `OSPV-0001`
- Approved Sources: `SRC-0001`
- Processes: `PROC-0001`
- Inspection Stages: `STG-0001`
- Quality Assets: `AST-0001`

Existing records and manually assigned codes remain unchanged.

## Dashboard Analytics

The dashboard adds dense KPI cards and pie charts for recent inwards, RMTC validation status and inward status, while retaining horizontal status bars.
