# QCMS v4.14.37 Release Notes

**Build:** `41437-MOBILE-FULL-NAV-COMPLAINT-CARDS-PO-APPROVAL-DRAFT-EMAIL`

## Complaint dashboard and email evidence
- Customer Complaint and Supplier Complaint status views now render as responsive **dashboard cards** instead of long unformatted text. Each card shows Complaint No., Customer/Supplier, subject, target date, severity, overall status, open-action count and six compact workflow-stage badges: Complaint, Containment, Root Cause, Corrective Action, Verification and Closure.
- Complaint email entry, saved-record email and Complaint Register email now provide an explicit **Send copy to Customer/Supplier** selection before the final recipient confirmation.
- Complaint email can attach the exact controlled **Complaint PDF** generated by the Complaint module plus active complaint photographs/supporting documents according to the configured email template.
- Complaint Email Configuration, delivery register and automatic Customer/Supplier/follow-up reminder schedules from v4.14.36 are preserved.

## Purchase Order pending approval worklist
- **Supply Chain → Purchase Order → Approval / Supplier Confirmation** begins with a Pending Approval worklist and KPI count.
- The table grid shows PO Number, Type, Supplier, Parts, Qty, dates, requisitioner, resolved approver, approver email, approval level, total and status.
- Employees may select one or multiple Pending Approval POs and choose **Email Selected Draft POs to Approver**.
- Every selected PO is sent separately to its resolved approver after a confirmation dialog with its controlled **PENDING APPROVAL** watermarked draft PO PDF attached.
- Existing approval routing, self-approval controls, editing/reapproval and Supplier Confirmation remain independent and preserved.

## Mobile application navigation
- Native Android and iPhone/iPad wrappers now own the complete mobile navigation. In native mode the Streamlit main rail, module submenu, Streamlit toolbar/header and desktop footer are not rendered.
- Mobile navigation follows the supplied reference-video interaction model: compact top bar, hamburger drawer, expandable module groups/submenus, full-width content and fixed bottom **Home / Search / Complaints** navigation.
- Native mode is detected from both `native_mobile=1` and the QCMS mobile user-agent, so Streamlit page switches cannot accidentally restore the long desktop menu.
- Android source version: **0.1.5**.
- iPhone/iPad universal source version: **0.1.2**.
- STAWN/QCMS application icon is preserved on both mobile platforms.

## Notification runtime
- v4.14.36 Complaint email templates/routes/schedules remain the live database baseline for Complaint Management.
- `qcms-overdue-notifier` v6 remains the controlled worker for complaint due/overdue/follow-up reminder schedules and respects `run_every_days` cadence.
- No additional database migration is required specifically for v4.14.37.

## Preserved controlled functionality
- v4.14.35 Supplier PO-confirmation reminder guard, supplier-safe PO print and PDF/Excel approval watermarks.
- One-click selected PO ZIP with an individual PDF per PO.
- Portrait PO Terms & Conditions, Part Description, PO edit/reapproval, Global Search, Bend Test, RMTC, OSP genealogy, MetLAB boundary, calibration, Standard Room, NPD/APQP, permissions and audit controls.

## Verification
- Release package requires complete Python compilation, online-readiness, phase verification and full pytest before packaging.
- Android APK requires Android SDK/JDK/Gradle build environment; iPhone/iPad IPA requires Xcode plus Apple signing/provisioning. Source/build helpers are supplied even when signed binaries cannot be produced in the packaging environment.
